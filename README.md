# 🌲 WildGuard

## Smart Forest Animal Alert System

WildGuard is a prototype designed to alert people when animals approach areas near forests.

### 🎯 Objective

To provide an early warning when animal movement is detected, helping reduce unexpected encounters between people and wildlife.

### ⚙️ How It Works

1. A PIR sensor detects movement.
2. The Arduino processes the detection.
3. An LED and buzzer provide a local alert.
4. A servo motor is activated.
5. A trigger signal is sent to the ESP32-CAM.
6. The ESP32-CAM receives the trigger and indicates that an image capture should occur.

### 🛠️ Hardware

- Arduino Uno
- PIR Sensor
- ESP32-CAM
- Servo Motor
- LED
- Buzzer
- FTDI Programmer
- Breadboard
- Jumper Wires

### 💻 Software

- Arduino IDE
- C/C++
- ESP32-CAM
